# Homebrew Tap for Aditya Pratap Singh

This repository contains Homebrew formulae for tools created and maintained by [@adityaiitg](https://github.com/adityaiitg).

## Installation

### CodeAtlas

Local codebase intelligence engine: AST-driven code IR, knowledge graph, living wiki & hybrid search.

```bash
# Add tap and install in one command
brew install adityaiitg/tap/codeatlas

# Or tap first, then install
brew tap adityaiitg/tap
brew install codeatlas
```

### Upgrading

```bash
brew upgrade codeatlas
```
